Privacy policy

auto upload. Last updated: 6 October 2026.

Who uses this app

auto upload is a personal tool. Only its owner uses it: the creator of the YouTube channel @pow3rcov3r.

What it accesses

With the owner's permission, given through Google sign-in, the app uses YouTube API Services to:

  • upload videos to the owner's channel and set their title, description, tags and thumbnail;
  • add videos to the owner's playlists and set when they go public;
  • read the list and status of the channel's own videos and playlists.

What it stores and shares

The sign-in token is stored only on the owner's computer. The app does not collect, sell or share any personal data, and it does not access data of any other person. This website uses no cookies, no analytics and no ads.

auto upload's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

This app uses YouTube API Services. Using it means agreeing to the YouTube Terms of Service. See also the Google Privacy Policy. The owner can remove the app's access at any time on the Google Account connections page.
